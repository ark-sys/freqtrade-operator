2. Check the status of your deployment:
  kubectl get deployment {{ include "freqtrade-operator.fullname" . }}-controller-manager -n {{ .Release.Namespace }}

3. View the controller manager logs:
  kubectl logs -f deployment/{{ include "freqtrade-operator.fullname" . }}-controller-manager -n {{ .Release.Namespace }}

4. The following Custom Resource Definitions have been installed:
  - TradeBots (tradebots.freqtrade.io)
  - TradeBotConfigs (tradebotconfigs.freqtrade.io)
  - Strategies (strategies.freqtrade.io)
  - FreqUIs (frequis.freqtrade.io)

5. You can now create Freqtrade resources using kubectl:
  kubectl apply -f your-freqtrade-resources.yaml
